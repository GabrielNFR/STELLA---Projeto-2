## Sobre o Projeto

**STELLA** é uma aplicação web desenvolvida para apoiar pacientes em tratamento de Fertilização In Vitro (FIV) da Clínica AMARE. A plataforma centraliza informações, medicações, consultas e documentos, devolvendo à paciente a sensação de controle e segurança durante todo o processo.

<details>
<summary><strong>Problema que Resolvemos</strong></summary>

Pacientes de FIV enfrentam protocolos complexos entregues em PDFs estáticos, comunicação fragmentada via WhatsApp e papel, ansiedade pela falta de visibilidade da jornada, dificuldade em gerenciar múltiplas medicações e sobrecarga cognitiva de memorizar horários, dosagens e etapas.

A STELLA oferece uma plataforma web mobile-first que visualiza a jornada completa em linha do tempo, gerencia medicações com alertas, registra sintomas e emoções, e permite a participação ativa do parceiro via modo co-piloto.

</details>

## Como Executar

<details>
<summary><strong>Execução Local</strong></summary>

### Pré-requisitos
- Python 3.13+
- Node.js 20+
- Git

### Backend

```bash
cd backend
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

API disponível em `http://localhost:8000`

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Aplicação disponível em `http://localhost:5173`

### Testes

```bash
cd backend
source venv/bin/activate
python manage.py test tratamento --verbosity=2
```

</details>
